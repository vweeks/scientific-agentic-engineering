# Introduction to Scientific Agentic Engineering

*This content is under development as part of Milestone 1 (July 2026).*

Scientific Agentic Engineering is a methodology for integrating AI coding agents into scientific software development workflows. Research software has split on these tools. Some teams adopted them faster than the practices for checking their output could catch up. Others stay away entirely, on the reasonable grounds that a plausible wrong answer is worse than no answer at all. This framework is an attempt at the practices that would serve both: making the first group’s work checkable, and giving the second group something to check with.
